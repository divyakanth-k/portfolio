Hidden Easter Eggs in the Command Palette

Back to Logs

While building this portfolio, I wanted to inject some of the classic DevOps and SysAdmin humor that infrastructure engineers deal with daily. Instead of just standard navigation, the site contains hidden commands inside the global Command Palette.

1. Accessing the Command Palette

First, to trigger the interface, simply press Cmd + K (or Ctrl + K on Windows). If you're on a mobile device, you can tap the search icon in the navigation bar.

"A good terminal is like a good joke; if you have to explain it, it's not that good. Unless it's an Easter egg, then you definitely need a blog post."

2. The 'sudo' Incident

We've all been there — trying to execute a command on a remote Linux server only to be met with permission denied. If you type sudo or su into the palette search bar, the UI will intercept it and throw the classic warning:

bash 
$ sudo root
User is not in the sudoers file. This incident will be reported to... yourself.

3. Kernel Panic (rm -rf /)

If you're feeling destructive and type hack or rm -rf /, the site will initiate a "system lockdown" and redirect you to a completely custom 404 page.

This 404 page simulates a Kubernetes Ingress Controller failure complete with time-stamped terminal logs, a blinking cursor, and an animated FATAL status message.

How it works

The Easter eggs are built in pure Vanilla JavaScript by catching specific strings in the palette's input event before the standard filtering logic runs:

javascript 
cmdInput.addEventListener("input", () => {
  const q = cmdInput.value.toLowerCase().trim();

  if (q === "rm -rf /") {
    window.location.href = "/404";
  }
});

Try them out for yourself right now by hitting Cmd+K!
